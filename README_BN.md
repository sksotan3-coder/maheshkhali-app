# AMAR MOHESHKHALI A TO Z
**Developed By: ST SOTAN** • Package: `com.st.sotan.amarmaheshkhali`

মহেশখালী উপজেলার (কক্সবাজার) জন্য সম্পূর্ণ অফলাইন Android তথ্যভান্ডার অ্যাপ।

## এখনকার অবস্থা (সৎভাবে)

| বিষয় | অবস্থা |
|---|---|
| Android Studio প্রজেক্ট (সব কোড ফাইল) | তৈরি হয়েছে |
| APK Build | **করা হয়নি।** যে কম্পিউটারে কোড লেখা হয়েছে, সেখানে Android SDK ছিল না এবং ডাউনলোডও বন্ধ ছিল |
| অ্যাপ চালিয়ে পরীক্ষা (install, crash, মেনু, সার্চ) | **করা হয়নি**, কারণ APK নেই |
| কোড কম্পাইল হয়েছে কি না | **যাচাই হয়নি।** প্রথম Build-এ ছোটখাটো error আসতে পারে, তখন error-টি আমাকে পাঠালে ঠিক করে দেব |
| তথ্য (ডেটা) | অধিকাংশ রেকর্ড **PENDING**। কিছু বানিয়ে লেখা হয়নি |

## APK বানানোর সহজ ধাপ

১. কম্পিউটারে **Android Studio** ইনস্টল করুন (ফ্রি, developer.android.com/studio)।
২. এই প্রজেক্ট ফোল্ডারটি (`AmarMoheshkhaliAtoZ`) আপনার কম্পিউটারে রাখুন (zip হলে আগে Extract করুন)।
৩. Android Studio খুলে **Open** চাপুন, তারপর `AmarMoheshkhaliAtoZ` ফোল্ডারটি বেছে নিন।
৪. নিচে "Sync" বা "Gradle" লেখা দেখা গেলে অপেক্ষা করুন। প্রথমবার ইন্টারনেট লাগবে এবং কয়েক মিনিট সময় লাগতে পারে। কোনো SDK ডাউনলোডের অনুরোধ এলে **Accept/Install** চাপুন।
৫. ওপরের মেনু থেকে **Build → Build Bundle(s) / APK(s) → Build APK(s)** চাপুন।
৬. শেষ হলে নিচে ডানে "locate" লেখা আসবে। সেখানে চাপলে `app-debug.apk` পাবেন (পথ: `app/build/outputs/apk/debug/`)।
৭. APK ফাইলটি ফোনে পাঠিয়ে ইনস্টল করুন (ফোনে "Unknown sources" অনুমতি দিতে হতে পারে)।

**Release APK** (Play Store বা বিতরণের জন্য): Build → Generate Signed Bundle / APK → APK। এখানে একটি signing key লাগে। সেটি আপনাকেই বানাতে হবে এবং key-র পাসওয়ার্ড নিরাপদে রাখতে হবে।

## কোনো error এলে
Android Studio-র নিচে **Build** ট্যাবে লাল লেখা দেখা গেলে সেটি কপি করে আমাকে পাঠান। আমি ঠিক করে দেব।

## প্রজেক্টে যা আছে
- Kotlin + Jetpack Compose + MVVM + Room (SQLite) + Navigation Compose
- বাংলা/English (অ্যাপের ভেতরেই পরিবর্তন করা যায়), Light/Dark থিম
- হোম, ৩৬টি তথ্য বিভাগ, ৮ ইউনিয়ন, অফলাইন সার্চ (ক্যাটাগরি ও ইউনিয়ন ফিল্টারসহ), প্রিয় তালিকা, সম্প্রতি দেখা, সেটিংস, অ্যাপ সম্পর্কে
- প্রতিটি রেকর্ডে Part 6-এর সব ফিল্ড এবং যাচাইয়ের অবস্থা (VERIFIED / PENDING / HISTORICAL / INFORMATION UNAVAILABLE)
- Login নেই, Cloud নেই, Internet permission নেই

## যা এখনো বাকি
- **তথ্য যাচাই ও পূরণ**: ওয়ার্ড, গ্রাম, বাজার, স্কুল, হাসপাতাল, ফোন নম্বর, জনপ্রতিনিধি, প্রকল্পের তথ্য ইত্যাদি এখনো যুক্ত হয়নি। সরকারি উৎস থেকে যাচাই করে `app/src/main/assets/seed/records.json` ফাইলে যুক্ত করতে হবে।
- **জরুরি নম্বর**: ৯৯৯ নম্বরটি সংবাদমাধ্যমে পাওয়া গেছে, কিন্তু সরকারি পোর্টাল থেকে যাচাই হয়নি, তাই PENDING দেখানো হয়।
- **অফলাইন মানচিত্র**: মানচিত্রের ডেটা এখনো যুক্ত হয়নি। কেবল স্থান-তথ্যের তালিকা আছে।
- **ছবি ও ভিডিও গ্যালারি**: লাইসেন্স-যাচাই করা ছবি পাওয়া না যাওয়া পর্যন্ত খালি।
- অ্যাপের ভেতরে ডেটা সংস্করণ বদলালে পুরনো ডেটা নতুন করে লোড হয় না। ডেটা আপডেটের জন্য এখনকার সংস্করণে অ্যাপ আনইনস্টল করে নতুন সংস্করণ বসাতে হবে।

## ফাইল কোথায় কী
- `app/src/main/java/.../data/` : ডেটাবেস (Room), ক্যাটাগরি ও ইউনিয়নের তালিকা
- `app/src/main/java/.../ui/` : সব স্ক্রিন ও ডিজাইন
- `app/src/main/assets/seed/records.json` : অ্যাপের সঙ্গে আসা তথ্য
- `app/src/main/AndroidManifest.xml` : অ্যাপের কনফিগারেশন
